Test lab

Three layers of testing, all in the browser. Nothing here has been run against real hardware yet; the first two are design-time evidence, the third is for your first board.

1. Design checks

Re-computes the model and parses the published fab files: Gerbers, drills, BOM, placement, KiCad board and case STLs. The same checks run in CI with npm test.

GroupCheckResultDetail

2. Pairing and latency simulator

Models the planned protocol: each blank target sends JOIN beacons until the host acknowledges; frames can be lost and simultaneous JOINs collide. Use it to size beacon interval, retries and fleet size before writing firmware.

Seeded and deterministic: the same inputs always give the same numbers. Radio loss is independent per frame; real interference is burstier.

3. Hardware bring-up

For your first built stick. Needs a Chromium-based browser (Web Serial). The ESP32-S3 native USB port appears as an Espressif device (VID 0x303A).

To flash a blank stick: short TP1 (BOOT) to TP2 (GND) while plugging in, then use esptool or esptool-js. Firmware is not published yet.
